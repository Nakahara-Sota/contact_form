# お問い合わせフォーム(Vanilla PHP版)

## 設計思想(開発コンセプト)

> **本ポートフォリオは、フレームワーク(Laravel等)に依存することなく、ネイティブなPHP(生PHP)が持つ機能を最大限に活用して実装を行いました。**<br>
> 初学者として便利なツールに頼る前に、Web開発の根幹である「セッション管理、データ検証、セキュリティ対策、データベース操作」の仕組みを本質的に理解し、自力で構築するスキルを養うことを目的としています。

## 画面イメージと主な機能

本システムでは、ユーザーが迷わず安全に問い合わせを完了できるよう、以下の画面と機能を備えています。

- **入力フォーム画面**: リアルタイム検証や一発消去ボタンを備えた快適なUI
- **確認画面**: 入力内容を最終確認し、二重送信を防ぐセキュリティを内包
- **完了画面**: 送信が成功したことをユーザーに通知

## 実装機能およびセキュリティ対策

<img width="1920" height="1020" alt="Image" src="https://github.com/user-attachments/assets/6deb46f7-dcb2-42d7-9dba-68b6b399349e" />

本ポートフォリオでは、生のPHPおよび純粋なJavaScript/CSSを用いて、以下の機能を網羅した堅牢なシステムを実装しています。

- **バリデーション(入力値検証)**
  - 検証ロジックを別ファイルに分離し、不正リクエストを遮断する設計にしました。
  - フォーム本来の目的を果たすため「お問い合わせ内容」の入力を必須化し、各項目で正規表現を使って未入力や空文字を検出しています。

- **コードのリファクタリング(関心の分離)**
  - **課題と改善**：初期段階で単一ファイルに混在しスパゲティコード化していたPHP、HTML、CSS、JavaScriptの記述(合計1万文字以上)を解体しました。
  - **成果**：各言語の役割ごとにファイルを適切に分離し、メインファイルのコード量を3,000文字強までスリム化。可読性と保守性を高めたクリーンな設計へと改良しました。

- **徹底したセキュリティ対策(安全性の確保)**
  - **二重登録・CSRF対策**：セッションを用いたワンタイムトークンにより、多重送信や不正な画面遷移をブロックします。
  - **スパム対策(ハニーポット)**：自動Botのみが反応する不可視の入力フィールドを設置し、スパム投稿を検知・排除します。
  - **データサニタイズ**：外部ライブラリに依存せず、プロジェクト内部に専用のクロスサイトスクリプティング対策関数を移植し、安全なデータ処理を行っています。

- **実用的なUI/UX(ユーザー操作性の向上)**
  - **リアルタイム文字数カウント**：JavaScriptにより入力文字数を画面上で動的に制御し、上限を超えた場合はカウンターを赤数字にします。
  - **一発消去ボタン**：各入力欄の横に配置したボタンをクリックすることで、入力内容を即座にリセットできる機能を追加しました。
  - **視認性の高いデザイン**：見出しをコールアウトデザイン化し、インラインスタイルをすべて外部CSSへ書き出してモダンな外観に整えました。

- **データ管理と運用環境の最適化**
  - データベースのテーブルに送信日時のカラムを追加し、いつ届いたかを正確に記録・管理できる設計にしました。
  - 現在はコメントアウトしていますが、レンタルサーバー環境下で実際に自動メール送信(mb_send_mail)が動作するロジックを組み込んでいます。

- **網羅的なエラーハンドリングと脆弱性隠蔽**
  - エラー検出の実装：不適切なリクエスト(400)、アクセス禁止(403)、巨大なデータ送信(413)といった各エラーパターンに対応するカスタムページをプロジェクト内に個別に実装
  - 集約による安全な誘導：実務(大企業のWebサイト等)のセキュリティ設計を参考に、.htaccess の設定によってこれらすべてのクライアントエラーを安全に 「404 Not Found」ページへと集約・リダイレクト させています。これにより、外部へ無駄なステータス情報を与えない「脆弱性の隠蔽(セキュリティ対策)」と、ユーザーを迷子にさせない「UI/UXの向上」を両立させています。

## セットアップ手順

1. **ファイルの配置**
   - 本プロジェクトのファイル群(`index.php` 等の表舞台ファイル、および裏方ファイルをまとめた `includes/` フォルダ)を、すべて `contact_form/php/` フォルダ内に配置してください。

2. **データベースの作成**
   - XAMPPの「MySQL」を起動し、`init.sql` をインポートしてデータベースを作成します。

3. **環境変数(.env)の作成 【重要】**
   - プロジェクトのルート(`contact_form/php/` 直下)に `.env` ファイルを新規作成します。
   - 同階層にある `.env.example` の内容をコピーし、ご自身のローカル環境に合わせてデータベースの接続情報(ユーザー名・パスワード等)を入力してください。

4. **ローカル環境(XAMPP)での起動方法**
   - XAMPP Control Panelを開き、**Apache** と **MySQL** を「Start」にします。
   - ブラウザを開き、以下のURLにアクセスしてください。
     ☞ `http://localhost/contact_form/php/`

## 使用技術

- **Backend**: PHP 8.0.30 (Vanilla PHP / 外部フレームワーク非依存)
- **Frontend**: HTML5, CSS3, bootstrap@5.3.8, JavaScript (Vanilla JS / 文字数カウント)
- **Database**: MySQL (MariaDB)
- **Development Environment**: XAMPP (Apache, MySQL)
- **IDE**: Visual Studio Code
